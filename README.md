# Sistema de Dados da COPA DO MUNDO
Plataforma de análise da Copa do Mundo. A aplicação integra banco de dados, visualização interativa e inteligência artificial para previsão de partidas.
# O que há na plataforma:
- Dashboard interativo para visualização dos grupos da Copa. 
- Escalações completas com fotos dos jogadores. 
- Visualização de estádios e árbitros. 
- Integração com API esportiva para estatísticas em tempo real. 
- Modelo de previsão de partidas usando Machine Learning. 
- Interface dinâmica com alteração de fundo conforme seleção escolhida.
# Tecnologias utilizadas
- Python
- Streamlit
- PostgreSQL
- SQLAlchemy
- Pandas
- Scikit Learn / XGBoost
- Kaggle Datasets
